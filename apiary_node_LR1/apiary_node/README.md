# Лабораторная работа 1

Проект apiary_node для ESP-IDF 5.3.x и Heltec WiFi LoRa 32 V4 с GPIO36 для Vext и GPIO37 для ADC_CTRL. Сверьте обозначение на плате. Версия V4-R8 имеет другую распиновку.

## Подключение

Отключите USB и аккумулятор перед монтажом. Проводите сигналы по обозначениям GPIO на плате. Земля всех модулей общая.

| Модуль | Сигнал | Подключение |
|---|---|---|
| HX711 | VCC, GND | 3V3, GND |
| HX711 | DOUT / DT | GPIO47 |
| HX711 | PD_SCK / SCK | GPIO48 |
| INMP441 | VDD, GND | 3V3, GND |
| INMP441 | SCK / BCLK | GPIO4 |
| INMP441 | WS / LRCLK | GPIO5 |
| INMP441 | SD / DOUT | GPIO6 |
| INMP441 | L/R | GND |
| Тензодатчик | E+, E− | E+, E− на HX711 |
| Тензодатчик | S+, S− | A+, A− на HX711 |

Для HX711 используйте режим 10 SPS (RATE = 0). Провода тензодатчика определяйте по паспорту. Если на INMP441 нет подтяжки SD к земле, установите резистор 100 кОм между SD и GND. OLED и PRG встроены. Для прогона достаточно USB-C. Для проверки батареи подключите один Li-ion/LiPo элемент 3,7 В с подходящим разъёмом к штатному BAT, предварительно сверив полярность контактов. Процент заряда приблизительный.

[Распиновка Heltec V4](https://resource.heltec.cn/download/WiFi_LoRa_32_V4/datasheet/WiFi_LoRa_32_V4.2.0.pdf) · [Отличия V4-R8](https://heltec.org/project/wifi-lora-32-v4/) · [Документация INMP441](https://product.tdk.com/system/files/dam/doc/product/sw_piezo/mic/mems-mic/data_sheet/inmp441.pdf)

## Сборка

Распакуйте архив и откройте терминал ESP-IDF 5.3.x в каталоге apiary_node.

```powershell
idf.py set-target esp32s3
idf.py build
idf.py -p COM5 flash monitor
```

Замените COM5 фактическим портом платы. Выход из монитора — Ctrl+].

## Проверка

1. После запуска OLED показывает статус LEAF. Удерживайте PRG не менее 1 с и отпустите. Короткое нажатие перемещает указатель, длинное подтверждает выбор. В журнале ожидается `role confirmed: GATEWAY`.
2. Раз в 5 с журнал показывает массу, число отсчётов, средний сырой код `raw_mean` и время последнего чтения HX711. При отключённом HX711 значение массы отсутствует. Частота HX711 номинальная, поэтому число отсчётов в 5-секундном интервале может отличаться от 50.
3. Звуковой замер выполняется при запуске и затем раз в минуту. Сравните RMS в тишине и при шуме непосредственно во время замера. Используются четыре окна по 1024 отсчёта с вычитанием среднего и окном Ханна.
4. Для проверки TWDT временно установите WATCHDOG_DEMO в 1, прошейте плату и откройте меню длинным нажатием. После испытания верните 0.

## Калибровка

Константы в components/config/node_config.h взяты из отчёта. Для своего тензодатчика запишите средний сырой код с двумя известными нагрузками в граммах. Рассчитайте SCALE_COUNTS_PER_GRAM = (raw2 − raw1) / (m2 − m1), затем SCALE_TARE = raw1 − SCALE_COUNTS_PER_GRAM × m1. Обновите обе константы, перепрошейте и проверьте третьим грузом. Для Li-ion процент заряда оценивается по таблице напряжений. Роль хранится в оперативной памяти. LoRa и Wi-Fi не используются в ЛР1.
